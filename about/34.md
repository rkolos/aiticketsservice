### HTTP Keep-Alive для Dify Client

**Цель:** Ускорить сетевое взаимодействие с API Dify за счет переиспользования TCP-соединений.

**Область изменений:** `src/infrastructure/dify/client.js`

**Описание задачи:** Настроить `axios` инстанс на использование `http.Agent` и `https.Agent` с включенным `keepAlive`.

**Техническая реализация:**

1.  Импортировать модули `http` и `https`.
    
2.  Создать агенты:
    
    JavaScript
    
        const agentOptions = { keepAlive: true, maxSockets: 100, maxFreeSockets: 10 };
        const httpAgent = new http.Agent(agentOptions);
        const httpsAgent = new https.Agent(agentOptions);
    
3.  Передать их в конфигурацию `axios.create()`:
    
    JavaScript
    
        const difyClient = axios.create({
          // ... существующие настройки
          httpAgent,
          httpsAgent,
        });
    

**Критерии приёмки (Acceptance Criteria):**

-   \[ \] При серии последовательных запросов к Dify используется одно и то же TCP соединение (можно проверить через `netstat` или логи уровня debug, если включить логирование сокетов).
    
-   \[ \] Отсутствуют ошибки `ECONNRESET` при высокой частоте запросов.
    
-   \[ \] `maxSockets` настроен и ограничивает количество одновременных соединений.
