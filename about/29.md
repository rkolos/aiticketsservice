# Техническое задание: Интеграция сервиса переводов (Translator Workflow)

**Контекст:** Для задачи перевода текста (`CMD_TRANSLATE`) ранее подразумевалось использование общей LLM или заглушки. Мы создали специализированный Workflow в Dify, который использует Google Translate. Это быстрее, дешевле и надежнее для задач чистого перевода.

**Цель:** Настроить обработку команды `CMD_TRANSLATE` в `fastLaneProcessor` так, чтобы она использовала новый API ключ и специфичные входные параметры.

## 1\. Обновление Конфигурации

Необходимо добавить новый API ключ в систему конфигурации.

### 1.1 Файл `.env` (и `.env.example`)

Добавить переменную:

Ini, TOML

    DIFY_APP_KEY_TRANSLATOR=app-5fM3rivzzW7vXrtcTP0OdvVg

### 1.2 Файл `src/config/schema.js`

Добавить валидацию для нового ключа:

JavaScript

    // В секции dify -> keys
    translator: {
      doc: 'Dify App Key for Translation Service',
      format: String,
      default: '',
      env: 'DIFY_APP_KEY_TRANSLATOR',
      sensitive: true,
    },

### 1.3 Файл `src/config/index.js` (если требуется)

Убедиться, что ключ доступен через `config.dify.keys.translator`.

## 2\. Обновление Fast Lane Worker (`src/workers/fastLaneProcessor.js`)

Задача `CMD_TRANSLATE` маршрутизируется в "быструю" очередь (см. `about/25.md`). Необходимо реализовать её обработку.

**Логика:**

1.  Проверить имя задачи. Если `CMD_TRANSLATE` — использовать спец. логику.
    
2.  Подготовить inputs согласно требованиям YAML (`text`, `lang`).
    
3.  Вызвать Dify API с ключом транслятора.
    
4.  Вернуть результат в стандартизированном виде.
    

**Код реализации (внутри switch/if блока процессора):**

JavaScript

    // ... внутри fastLaneProcessor ...
    
    if (job.name === 'CMD_TRANSLATE') {
      // 1. Подготовка данных
      // Ожидаем в job.data: { text: "Hello", targetLang: "ru" }
      const inputs = {
        text: job.data.text,
        // Маппинг targetLang в lang (как требует YAML)
        lang: job.data.targetLang || job.data.lang || 'en' 
      };
    
      const apiKey = config.dify.keys.translator;
    
      // 2. Вызов Dify
      // Используем runWorkflow, так как это Workflow-тип приложения
      const result = await difyApi.runWorkflow(apiKey, inputs, user);
    
      // 3. Формирование ответа
      // Обычно Workflow возвращает результат в outputs.text или outputs.result
      // Нужно проверить, как именно возвращает этот YAML (обычно это поле "text" в End ноде)
      const translatedText = result.data.outputs.text || result.data.outputs.result || result.data.answer;
    
      return {
        original: inputs.text,
        translated: translatedText,
        targetLang: inputs.lang,
        // Можно добавить метаданные использования, если Dify их возвращает
        usage: result.data.usage 
      };
    }
