# Техническое задание: Slow Lane Worker - Этап 2: Dify Upload Client (Доработка uploadFile)

**Контекст:** Загрузка файлов в `about/9.md` критична из-за потоков и таймаутов. На втором этапе дорабатывается метод `difyApi.uploadFile` для поддержки `form-data` с параметром `knownLength`, что предотвращает проблемы с chunked-кодированием при загрузке больших файлов.

**Цель:** Доработать метод `difyApi.uploadFile` в `src/infrastructure/dify/api.js` для корректной работы с потоками файлов, поддержки `knownLength` в `form-data` и предотвращения использования `Transfer-Encoding: chunked`.

## 1. Задачи реализации

### 1.1 Доработать метод `uploadFile` в `src/infrastructure/dify/api.js`

**Назначение:** Метод должен корректно формировать `multipart/form-data` с поддержкой `knownLength` для предотвращения chunked-кодирования.

**Текущая сигнатура (из `about/5.md`):**

```javascript
uploadFile(apiKey, datasetId, fileStream, fileName, user = 'system', fileSize = null)
```

**Алгоритм доработки:**

1.  **Проверить наличие библиотеки `form-data`:**
    
    -   Убедиться, что `form-data` установлена в проекте (см. `about/5.md`, раздел 1).
        
    -   Импортировать библиотеку: `const FormData = require('form-data');`.
        
2.  **Создать экземпляр FormData:**
    
    -   Создать новый экземпляр: `const formData = new FormData();`.
        
3.  **Добавить поле `file` в FormData:**
    
    -   **Важно:** Если передан параметр `fileSize` (размер файла в байтах), необходимо указать его в опциях `form-data` как `knownLength`. Это предотвратит использование `Transfer-Encoding: chunked`.
        
    -   Пример добавления файла:
        
        ```javascript
        if (fileSize !== null && fileSize !== undefined) {
          formData.append('file', fileStream, {
            filename: fileName,
            knownLength: fileSize
          });
        } else {
          formData.append('file', fileStream, {
            filename: fileName
          });
        }
        ```
        
    -   **Примечание:** Если `fileSize` не передан, `form-data` будет использовать chunked-кодирование. Рекомендуется всегда передавать размер файла, если он известен (например, из заголовка `content-length` при скачивании через `FileService.downloadStream`).
        
4.  **Добавить поле `data` в FormData:**
    
    -   Поле `data` должно содержать JSON строку с правилами индексации:
        
        ```javascript
        const data = JSON.stringify({
          indexing_technique: 'high_quality', // или другое значение из конфига
          process_rule: {
            mode: 'automatic',
            rules: {}
          }
        });
        
        formData.append('data', data);
        ```
        
    -   **Примечание:** Правила индексации могут быть настраиваемыми через конфиг (опционально).
        
5.  **Настроить заголовки запроса:**
    
    -   Получить заголовки от `formData.getHeaders()` для Boundary:
        
        ```javascript
        const headers = {
          ...formData.getHeaders(),
          'Authorization': `Bearer ${apiKey}`
        };
        ```
        
    -   **Важно:** Не устанавливать заголовок `Content-Length` вручную — `form-data` сделает это автоматически при использовании `knownLength`.
        
6.  **Отправить запрос через Axios клиент:**
    
    -   Использовать настроенный инстанс Axios из `client.js`.
        
    -   Метод: `POST /datasets/{datasetId}/document/create_by_file`
        
    -   URL: `${baseURL}/datasets/${datasetId}/document/create_by_file`
        
    -   Body: `formData` (Axios автоматически обработает FormData)
        
    -   Headers: заголовки от `formData.getHeaders()` + Authorization
        
    -   **Важно:** Axios клиент должен иметь настройки `maxBodyLength: Infinity` и `maxContentLength: Infinity` (см. `about/5.md`, раздел 2.3).
        
7.  **Обработать ответ:**
    
    -   Вернуть результат от Dify (обычно объект с `document_id` и статусом `indexing`).
        
    -   Обработать ошибки через интерцептор Axios (должен выбрасывать `DifyApiError`).

**Зависимости:**

-   `form-data` (библиотека для формирования multipart/form-data).
    
-   `axios` клиент из `client.js` (с настройками `maxBodyLength: Infinity`, `maxContentLength: Infinity`).
    
-   Конфигурация (`config.dify.url`).

## 2. Структура файла

**Файл:** `src/infrastructure/dify/api.js`

**Дополнения к существующему коду:**

-   Импортировать `FormData`: `const FormData = require('form-data');`.
    
-   Доработать метод `uploadFile` согласно алгоритму выше.

**Пример реализации:**

```javascript
async function uploadFile(apiKey, datasetId, fileStream, fileName, user = 'system', fileSize = null) {
  const formData = new FormData();
  
  // Добавить файл с knownLength, если размер известен
  if (fileSize !== null && fileSize !== undefined) {
    formData.append('file', fileStream, {
      filename: fileName,
      knownLength: fileSize
    });
  } else {
    formData.append('file', fileStream, {
      filename: fileName
    });
  }
  
  // Добавить данные индексации
  const data = JSON.stringify({
    indexing_technique: 'high_quality',
    process_rule: {
      mode: 'automatic',
      rules: {}
    }
  });
  formData.append('data', data);
  
  // Получить заголовки
  const headers = {
    ...formData.getHeaders(),
    'Authorization': `Bearer ${apiKey}`
  };
  
  // Отправить запрос
  const response = await difyClient.post(
    `/datasets/${datasetId}/document/create_by_file`,
    formData,
    { headers }
  );
  
  return response.data;
}
```

## 3. Тестирование

### 3.1 Unit-тест с моком Axios и FormData

**Цель:** Проверить корректное формирование FormData с `knownLength`.

**Тесты:**

-   **Загрузка с knownLength:**
    
    -   Вызвать `uploadFile` с параметром `fileSize: 1024`.
        
    -   Проверить, что `formData.append` вызван с опциями `{ filename, knownLength: 1024 }`.
        
    -   Проверить, что заголовки от `formData.getHeaders()` используются в запросе.
        
-   **Загрузка без knownLength:**
    
    -   Вызвать `uploadFile` без параметра `fileSize` (или `null`).
        
    -   Проверить, что `formData.append` вызван без опции `knownLength`.
        
-   **Проверка поля `data`:**
    
    -   Проверить, что поле `data` добавлено в FormData с корректным JSON.
