### ТЗ №2. Кэширование энкодера токенов (`tokenCounter`)

**Цель:** Убрать накладные расходы на инициализацию WASM-модуля `tiktoken` при каждом вызове подсчета токенов.

**Область изменений:** `src/utils/tokenCounter.js`

**Описание задачи:** Реализовать паттерн Singleton или ленивую инициализацию для объекта `encoding`.

**Техническая реализация:**

1.  Объявить переменную модуля (например, `let cachedEncoding = null;`).
    
2.  В функции `countTokens`:
    
    -   Если `modelName` поддерживается и `cachedEncoding` не инициализирован (или отличается модель), вызвать `encoding_for_model(modelName)` и сохранить результат.
        
    -   Использовать сохраненный инстанс для метода `.encode()`.
        
3.  **Убрать** вызов `encoding.free()` после каждого использования.
    
4.  (Опционально) Добавить метод `cleanup()`, который вызывает `.free()`, для использования при Graceful Shutdown приложения.
    

**Критерии приёмки (Acceptance Criteria):**

-   \[ \] При нагрузочном тестировании (1000 вызовов подряд) время выполнения снизилось минимум на 30%.
    
-   \[ \] Память не течет (инстанс переиспользуется, а не создается новый каждый раз).
    
-   \[ \] Поддерживается переключение моделей (если `modelName` изменился, создается соответствующий энкодер).
